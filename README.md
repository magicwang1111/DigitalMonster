# 基尔兽

## 一键启动

双击项目根目录的 **启动基尔兽.bat**。当前机器使用 `D:\miniconda3\pythonw.exe`；换机器时修改 BAT 中的 `DM_PY`。需要 Python、Pillow、Tkinter、Windows OpenSSH，以及配置好的 `seetacloud-5090x2` SSH 连接。运行失败可在终端执行 `python -m digitalmon.desktop` 查看错误。

桌面快捷方式也可启动。网络或服务器不可用时会显示连接错误；不会另建一个新个体冒充原来的基尔兽。

## 一个个体、一份学习状态

每只基尔兽的个体 UUID 同时作为宠物网络 ID，网络权重、驱动状态、最近行动、学习更新次数保存在同一个 SQLite 个体状态中。换外观不换模型，重启恢复同一个模型。界面从服务器读取真实网络行动，而不是用离线实验分数解释宠物行为。

当前网络是小型可检查的感知—动作关联网络。内部驱动输入连接到观察、索食、寻求抚摸、休息等输出；照料事件以明确的监督关联更新权重，并记录更新前后数值及原因。这仍是初级关联学习，不等同于自主发现复杂奖励，也没有实现 Dosidicus 完整的神经发生和突触可塑性机制。

参考项目 [Dosidicus](https://github.com/ViciousSquid/Dosidicus) 的共同学习引擎、可观察网络及经历影响行为的设计方向。本项目没有复制其源码。

## 互动与动画

点击摸摸或喂食。普通食物为金黄色十字纹圆面包，累计喂食会遇到基尔兽造型面包彩蛋。嘴、手臂、尾巴的喂食动作使用独立姿态帧。右键图鉴可预览其他形态；预览不代表已经进化。

## 当前边界

大地图模型属于早期导航实验，不再作为宠物进化依据。自动进化采用养成规则：古拉兽需要喂食10次、摸摸10次、学习更新30次、有效活动1200步及探索3个不同来源；大古拉兽对应30/30/100/7200/6；红莲骑士兽对应80/80/250/21600/10。条件必须同时满足，沿用同一网络并记录进化事件。这些是养成里程碑，不是模型能力或意识认证。CM/X 当前仅提供形象预览。当前模型只学习有限照料关联；尚无自由语言理解、通用智能或意识证明。

## 桌面悬停交互

平时只显示角色，不显示状态文字。鼠标移到角色上出现摸摸、喂食、探索和进化选项，移出后收起。空闲时角色可在桌面二维移动，鼠标悬停、拖动或互动时暂停。右键“固定在当前位置”停止位移；“解除固定，自由活动”恢复，固定开关和固定时的位置会保存到本地。按住左键拖动角色；右键提供暂停、继续及关闭。关闭窗口或按 Esc 只关闭桌面端，服务器继续运行。“探索”排队读取公共资料并保存来源，目前采用官方文档目录作为受限探索课程，不具备任意互联网内容的自主理解。“进化”显示条件及实际进度，条件达成后播放对应形态转换动画。观察台已移除旧地图。

实际移植的代码及来源版本见 [第三方说明](THIRD_PARTY_NOTICES.md)。Dosidicus 的可塑性引擎已参与同一网络的驱动到动作权重更新；Voyager 的任务去重逻辑用于完成/失败记录，探索会选择未完成且失败较少的课程。没有移植完整的 STDP、神经发生、LLM 或开放式代码技能生成。代码采用 GPL-2.0，MIT 部分保留原许可。

## 数据与服务

远端项目根目录 `/root/autodl-tmp/DigitalMonster`，个体状态位于 `data/life.sqlite`。令牌在 `data/access.token`；本地连接令牌放在已忽略的 `data/remote.token`，不要提交。服务启动：`bash /root/autodl-tmp/DigitalMonster/app/scripts/remote-service.sh start`。

测试：`python -m unittest discover -s tests -v`。

## 探索记录与模型文件

观察台“联网探索记录”显示任务状态、访问时间、实际网址、页面标题和已保存的内容原文。失败任务显示错误，未完成任务不伪造结果。成功读取会保存资料记忆、更新已完成课程和来源记录；这不意味着模型已经理解网页语义，也不会把下载网页宣称为模型训练。

个人宠物网络的在线权重保存在远端 SQLite。桌面连接后每轮同步将带 SHA256 的网络快照原子保存到本地 `data/companion-model.json`。这是本地备份快照，当前桌面端仍连接服务器运行，不是完整离线模式。快照包含网络参数、内部驱动和观察窗口，不包含访问令牌或用户聊天原文；它仍属于个人存档，默认不提交 GitHub。

GitHub 包含模型实现 `digitalmon/brain.py`、上游可塑性模块及真正用于创建新个体的初始参数 `digitalmon/model_defaults.json`。初始参数是未学习的模板，不冒充当前基尔兽训练后的权重。其他人下载代码后可创建自己的个体。

行走动画现在依据对应待机形态的实际可见高度、脚底锚点缩放，而不是统一放大到220像素。四个主线形态的行走帧已重绘，使用交替腿步与对侧摆臂的循环。
