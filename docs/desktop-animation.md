# 桌面像素互动

双击桌面“初生-基尔兽”打开。点击“喂食”播放接过圆面包、送到嘴边、咬下和咀嚼的逐帧动作。金黄色圆面包与十字割纹依据用户参考；隐藏的基尔兽造型面包随累计喂食触发，计数保存在远端个体状态中，重启不丢失。

六种形态：基尔兽、古拉兽、大古拉兽、红莲骑士兽、红莲骑士兽 CM、红莲骑士兽 X 抗体。嘴、手臂和尾巴的变化来自独立生成的姿态帧，不再以整张图轻跳代替喂食。骑士形态没有尾巴，以披风或羽翼动作替代。CM 使用红金装甲、暗色圆胸核和白色羽翼，X 使用白金装甲、红披风和青色部件。

右键“像素动作图鉴（预览）”可看尚未解锁的形态；这只改变展示，不改变个体成长记录。选择“恢复真实成长形态”返回实际形态。关闭桌面窗口不停止远端个体。

素材来源位于 `digitalmon/static/pet/sources/`。执行 `python scripts/export_articulated.py` 从生成动作表导出透明 GIF，统一缩放比例与脚底锚点。运行 `python -m unittest discover -s tests -v` 验证逐帧数量、帧差异、透明度以及彩蛋持久化。

主线形态的旧待机/摸摸仍保留原有轻跳特效；本次主要重做六形态的喂食动作，并为 CM/X 增加独立待机和摸摸姿态。外观和亲密度属于交互呈现，不能作为主观意识的证据。
